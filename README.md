# Clube do Dominó

Este repositório contém o código-fonte do aplicativo **Clube do Dominó**.

## Estrutura do Projeto

O projeto é um aplicativo móvel Android, desenvolvido utilizando Kotlin e Gradle, com potencial integração a um servidor backend.

- **Aplicativo Android**:
  - `app/`: Código-fonte principal da aplicação Android.
  - `ui/`: Componentes de interface do usuário.
  - `build.gradle.kts`, `settings.gradle.kts`: Configurações de build do Gradle.

- **Backend / Servidor**:
  - `server/`: Código-fonte ou arquivos relacionados ao servidor do aplicativo.

- **Documentação e Recursos**:
  - `docs/`: Documentações adicionais.
  - `avatares/`: Recursos gráficos (avatares) utilizados no jogo/aplicativo.
  - `RESUMO_ATUALIZACAO_FINANCEIRA.md`: Resumo de atualizações financeiras do projeto.

- **Outros**:
  - Pastas `apks/` e `versoes/` para armazenamento de builds e releases.
  - Diversos arquivos de log de build (`build_log.txt`, etc.) utilizados para debug.

## Tecnologias Utilizadas
- **Linguagem Principal**: Kotlin
- **Build System**: Gradle
- **Plataforma**: Android
